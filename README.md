# উদ্যোগ (UDYOG) আবেদন সহায়ক

উদ্যোগ (UDYOG) তরুণ উদ্যোক্তা অর্থায়ন কর্মসূচির আবেদন ফরম ধাপে ধাপে পূরণ করার একটি সম্পূর্ণ ক্লায়েন্ট-সাইড টুল।

- প্রতিটি অক্ষর ব্রাউজারের localStorage-এ অটোসেভ হয়; কোনো সার্ভার নেই
- ড্যাশবোর্ড: একাধিক আবেদন প্রিভিউ, এডিট, ডুপ্লিকেট, ব্যাকআপ/ইমপোর্ট
- প্রিভিউ ও প্রিন্ট: অফিসিয়াল PDF ফরমের হুবহু ৭ পৃষ্ঠা (ভেক্টর), ব্রাউজারের "Save as PDF" দিয়ে PDF

Stack: HTML, Tailwind CSS v4 (browser CDN), Lucide icons, vanilla JS. No build step.

> এটি একটি স্বাধীন ফরম পূরণ সহায়ক টুল, বাংলাদেশ ব্যাংকের অফিসিয়াল ওয়েবসাইট নয়।
